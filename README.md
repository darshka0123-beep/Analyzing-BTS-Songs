# Project description 
A python data analysis script built in VS code that analyzes data from a dataset containing various BTS songs.

# Why I built it
I was learning more about pandas and using csv's and I wanted to connect it to something I liked as an ARMY.

# What I learned
Loading and manipulating csv datasets using pandas
Filtering details like album titles, duration of songs, and creating histograms and scatter plots. 

# What I struggled on
The scatter plot was looking really wonky so I had to change a few things. 

# How to run
Open vs code and make sure you have pandas and python installed
